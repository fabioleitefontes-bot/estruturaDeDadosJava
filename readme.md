# 🚀 Estrutura de Dados & Java Stream API

Este repositório foi criado para documentar a resolução de desafios práticos e exercícios focados na manipulação de coleções, lógica de programação e uso aprofundado da **Stream API** do Java.


---

## 📂 Direção das Implementações

Navegue pelas pastas do projeto através dos links diretos abaixo:

*   **[Exercício 1 (Lista)](src/main/Java/exercicios/ex1)**: Exercícios práticos focados na manipulação e estrutura de **Lists**.
*   **[Exercício 2 (Set)](src/main/Java/exercicios/ex2)**: Desafios focados na estrutura de **Sets**.
*   **[Exercício 3 (Map)](src/main/Java/exercicios/ex3)**: Práticas focadas na estrutura de **Maps**.
*   **[Implementações Básicas](src/main/Java/implementacao)**: Códigos de estudo e fundamentos das principais estruturas de dados (**List, Map, Queue, Stack, HashSet e HashCode**).
*   **[Desafio Stream API](src/main/Java/streanApi)**: Resolução de desafios práticos utilizando os métodos e o paradigma funcional da Stream API no arquivo `desafio.java`.

---

## 💻 Tecnologias Utilizadas

*   **Java 21** 
*   **Java Stream API** (Paradigma Funcional / Expressões Lambda)
*   **IntelliJ IDEA**
